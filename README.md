# anki-customizations

Personal Anki tweaks.

## Features

- **Ctrl+R while studying**: opens the Browser and searches
  `deck:Japanese::RTK "<selected text>"`. It only exists in the study screen,
  and Anki doesn't use Ctrl+R there. The key and deck can be changed in the
  add-on's config (`rtk_search_shortcut`, `rtk_search_deck`).
